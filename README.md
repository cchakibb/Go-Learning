# Go Specialization Projects

Hands-on projects built during my Go specialization after 3 years of systems programming at 42 Berlin.

## Projects

*Note: These flagship projects are currently nested within weekly progress directories. They will eventually be extracted into dedicated repositories for easier direct access.*

### 1. REST API with PostgreSQL & Docker
**Path:** `week_07/hotel-postgres`
A fully functional RESTful API for hotel management featuring PostgreSQL database integration and Docker containerization. This project demonstrates proficiency in HTTP routing, relational data persistence, middleware integration, and containerized deployments.

### 2. Concurrent Availability Simulator
**Path:** `week_04/availability`
A concurrent system designed to simulate and manage real-time room availability checks. This project demonstrates safe state management and advanced concurrency patterns using Goroutines and Channels.

### 3. CLI Task Tracker
**Path:** `week_01/Task-Tracker/task-tracker`
A command-line interface application built to efficiently manage and track daily tasks. This project demonstrates mastery of the Go standard library for file I/O operations and CLI tool structuring.
